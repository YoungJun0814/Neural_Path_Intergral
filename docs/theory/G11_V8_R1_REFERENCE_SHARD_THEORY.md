# G11 V8 R1 sharded-reference correctness note

Date: 2026-07-31  
Scope: finite-grid ordinary Monte Carlo / importance-sampling references  
Status: implementation theorem and falsification contract, not a performance result

## 1. Estimand and filtration

For one fixed cell and one fixed reference method, let \(Y\) denote the ordinary
importance-sampling contribution under the frozen proposal. The target is

\[
\theta = \mathbb E_Q[Y],
\]

where \(Y=h(X)\,dP/dQ\) for the raw reference, or the corresponding conditionally
integrated contribution for DCS. This note does not change the estimand and does not
permit self-normalization.

Let \(\mathcal P\) be the sigma-field generated by all pilot shards. The final sample
count is the integer

\[
N(\mathcal P)=\max\!\left\{N_{\min},
\left\lceil s^2\,\widehat v_{\max}/\varepsilon^2\right\rceil\right\},
\]

where \(\widehat v_{\max}\) is the maximum variance across the predeclared pilot
replicates, \(s^2\ge1\) is the frozen safety factor, and \(\varepsilon\) is the
target standard error. If this count exceeds the resource cap, execution fails
before any final draw. It is never clipped and reported as complete.

## 2. Conditional unbiasedness

The final namespace and every final seed key are disjoint from the pilot namespace.
Conditional on \(\mathcal P\), the final contributions \(Y_1,\ldots,Y_N\) use the
frozen proposal and are independent of the pilot. Hence

\[
\mathbb E\!\left[\widehat\theta_N\mid\mathcal P\right]
=\mathbb E\!\left[\frac1N\sum_{i=1}^{N}Y_i\mid\mathcal P\right]
=\theta.
\]

Taking expectations again gives \(\mathbb E[\widehat\theta_N]=\theta\). This
argument does not justify extending, censoring, or discarding the same final stream
after seeing its outcomes. The implementation therefore stores the exact final
count and exact chunk roster in an immutable allocation manifest.

## 3. Exact shard aggregation

Each shard stores \((n,\bar y,M_2)\), where

\[
M_2=\sum_{i=1}^{n}(y_i-\bar y)^2.
\]

For two disjoint shards \(A,B\), with
\(\delta=\bar y_B-\bar y_A\) and \(n=n_A+n_B\), Chan's merge is

\[
\bar y=\bar y_A+\delta\frac{n_B}{n},\qquad
M_2=M_{2,A}+M_{2,B}+\delta^2\frac{n_A n_B}{n}.
\]

This identity is algebraically equal to processing every observation in one
sequence. The unbiased sample variance is \(M_2/(n-1)\). In particular, the
implementation never averages shard means with equal weights, which would be wrong
when chunk sizes differ.

Floating-point addition is not associative, so arbitrary merge order need not be
bitwise identical. The production aggregator uses the frozen manifest order.
Interrupted and uninterrupted runs therefore load and merge the same immutable
records in the same order and must produce an identical canonical aggregate.

## 4. Checkpoint semantics

A checkpoint is a complete canonical JSON artifact installed by an atomic,
non-overwriting filesystem operation. A temporary file is not a checkpoint.
Restart logic:

1. validates every completed shard;
2. maps it to its content-derived identity;
3. skips only an exact expected identity;
4. recomputes an absent chunk with the same frozen seed key; and
5. refuses to replace any completed path.

The final aggregator rejects missing, duplicate, foreign-parent, wrong-count,
wrong-hash, dirty-source, invalid-path, nonfinite, and seed-collision inputs.

## 5. Acceptance gates

For each method-cell pair, the ordinary standard error must meet its frozen target,
and the likelihood normalization diagnostic must satisfy \(|z|\le4\). For each
cell, independent DCS and raw estimates must satisfy

\[
z_{\mathrm{agree}}=
\frac{|\widehat\theta_{\mathrm{DCS}}-\widehat\theta_{\mathrm{raw}}|}
{\sqrt{\mathrm{SE}_{\mathrm{DCS}}^2+\mathrm{SE}_{\mathrm{raw}}^2}}
\le 4.
\]

These are diagnostics and acceptance gates, not proofs that an implementation is
correct. Hash binding, exact-set validation, analytic oracles, corruption tests,
and independent code review remain separate obligations.

## 6. Scope boundaries

- This establishes finite-sample estimator and restart semantics, not a new
  continuous-time theorem.
- DCS and raw independence must be created by disjoint seed families; sharing paths
  would require a covariance-aware agreement statistic.
- CPU/float64 is the only validated backend in R1.
- Passing R1 authorizes R2 infrastructure use only. It does not authorize a
  performance claim, P8 qualification, or journal submission.
